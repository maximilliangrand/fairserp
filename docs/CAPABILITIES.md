Generated by `scripts/capabilities.py` from each adapter's declared metadata. Do not edit
by hand. "Strict" means the engine runs under the default profile without an opt-in.
Rights reflect the providers' published terms as read on the review date; your own
agreement with a provider takes precedence. Not legal advice.

Terms reviewed per engine:

- **brave**: [https://api-dashboard.search.brave.com/terms-of-service](https://api-dashboard.search.brave.com/terms-of-service), reviewed 2026-10-23. Standard terms limit storage, redistribution and some AI uses; an order form can change this. Results are never cached or archived by default.
- **mojeek**: [https://www.mojeek.com/services/search/web-search-api/](https://www.mojeek.com/services/search/web-search-api/), reviewed 2026-10-23. Entry plans allow caching for up to one hour; longer storage needs a plan that grants storage rights.
- **marginalia**: [https://about.marginalia-search.com/article/api/](https://about.marginalia-search.com/article/api/), reviewed 2026-10-23. Free and shared 'public' keys license results CC-BY-NC-SA 4.0 (noncommercial).
- **tavily**: [https://tavily.com/terms](https://tavily.com/terms), reviewed 2026-10-23. Does not disclose where results come from. Its answer field is model-generated.
- **firecrawl**: [https://www.firecrawl.dev/terms-of-service](https://www.firecrawl.dev/terms-of-service), reviewed 2026-10-23. Index provenance undisclosed; live results carry Google's srsltid parameter. Keyless tier is capped per IP.
- **searxng**: [https://docs.searxng.org/](https://docs.searxng.org/), reviewed 2026-10-23. Rights follow the upstream engines your instance enables.
- **wikipedia**: [https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use), reviewed 2026-10-23. Share-alike applies to reused text. API etiquette requires an identifying UA.
- **wikidata**: [https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use), reviewed 2026-10-23.
- **duckduckgo_ia**: [https://duckduckgo.com/api](https://duckduckgo.com/api), reviewed 2026-10-23. Each abstract states its source (usually Wikipedia).
- **openstreetmap**: [https://operations.osmfoundation.org/policies/nominatim/](https://operations.osmfoundation.org/policies/nominatim/), reviewed 2026-10-23. Public Nominatim: 1 request/second, caching required, no resale of geocoding. OSM has no ratings or reviews; those fields stay unknown.

## SerpApi migration endpoint

| SerpApi feature | fairserp behavior |
|---|---|
| `engine=google`, `bing`, `duckduckgo`, ... | Refused unless mapped in `FAIRSERP_SERPAPI_ENGINES` (e.g. `google:auto`). fairserp never queries Google or Bing |
| `q`, `num`, `start`, `first`, `count` | Applied |
| `gl`/`cc`, `hl`, `mkt`, `kl` | Mapped to country/language; reported ignored when the answering engine cannot apply them |
| `safe=active` | Enforced. Engines that cannot filter are skipped; if none can, the request is refused (400) |
| `tbs=qdr:h/d/w/m/y`, `df` | Mapped to freshness when the engine supports it, else reported ignored. Other `tbs` values are reported ignored |
| `location` | Drives local results (OpenStreetMap) and engines that accept a location |
| `device`, `google_domain`, `uule`, `lr`, `cr`, `filter`, `nfpr`, `ludocid`, `kgmid`, ... | No equivalent; reported in `search_metadata.fairserp.params.ignored` |
| `fairserp_strict=true` | Reject instead of report when any param cannot be applied |
| `no_cache`, `async`, `zero_trace`, `output=json/html/md`, `json_restrictor` | Supported. `async` is refused for providers whose terms forbid storage; async jobs are not durable across restarts |
| `organic_results`, `knowledge_graph`, `answer_box`, `related_questions`, `related_searches`, `local_results`, `pagination`, `serpapi_pagination` | Rendered when a provider supplies them |
| `ai_overview` | Only for model-generated answers (Tavily), marked `fairserp_generated: true` |
| `ads`, `top_stories`, `shopping_results`, `inline_images`, Google verticals | Not available from any permitted source |
| Google rankings (rank tracking) | Not possible: fairserp results are not Google results |
